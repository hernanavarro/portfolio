# Portfolio — Hernán Navarro

Sitio personal de presentación. Landing de una sola página, dark-mode, con estética de editor de código: sidebar de navegación tipo árbol de archivos, terminal animada en el hero, y secciones de experiencia, stack, proyectos, educación y contacto.

- **Stack:** HTML + CSS + JS vanilla, un solo archivo (`index.html`).
- **Tipografía:** IBM Plex Mono (headings/labels) + Manrope (cuerpo), vía Google Fonts.
- **Deploy:** Vercel.

## Desarrollo local

No requiere build ni dependencias — es un único archivo estático:

```bash
open index.html
```
